| # | 素材 | Content 路径 | 来源 |
|---|------|-------------|------|

**获取方式（方案B：模板迁移）**：
1. Epic Launcher → 新建项目，模板选 **Third Person**，项目名随意，路径随意
2. 打开模板项目，Content Browser 中展开 `Content/Characters/Mannequins/`
3. 右键 `Mannequins` 文件夹 → **Asset Actions → Migrate...**
4. 导航到本项目路径 → 选 `Content` 文件夹 → 确认
5. 迁移完成后关闭模板项目，回到本项目

迁移后的资产：
- `SKM_Manny` + `SK_Manny_Skeleton` + `SK_Manny_PhysicsAsset`
- `ABP_Manny`（完整的第三人称动画蓝图，EventGraph + AnimGraph 都已配好）
- Idle / Walk / Run / Jump 基础动画

## 三、FBX 导入 UE5 设置

Mixamo 下载的 `.fbx` 拖入 Content Browser 后，在 Import 弹窗中设置：

| 选项 | 值 |
|------|-----|
| Skeleton | `SK_Mannequin_Skeleton`（模板迁移后的骨骼名，在 `Mannequins/Meshes/` 下） |
| Import Mesh | ❌ 取消（只要动画） |
| Import Animations | ✅ 勾选 |
| Animation Length | `Exported Time` |
| Import Uniform Scale | `1.0` |

如果导入后角色朝向异常（头朝地等），在动画资产中调整 Rotation 偏移，通常 UE5 新版导入器已自动处理 Y-up → Z-up 转换。

## 四、下载顺序建议

模板迁移后自带 Idle/Walk/Run/Jump + ABP_Manny + BS_Locomotion，**可跳过 B1~B3,B8 和 D1,F1 的手动创建**。

1. **先迁移模板** → C1 BP_GASCharacter 挂 SKM_Manny + ABP_Manny → 角色能动
2. **再下载 B9**（Cast）→ 手搓 C2 火球蓝图 + E1 AM_Cast → 做 Step 1.2 弹道技能
3. **逐步补齐** B4~B12，跟着 Step 推进

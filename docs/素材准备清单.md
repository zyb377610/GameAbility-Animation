### D. 动画蓝图

| # | 素材 | Content 路径 | 说明 |
|---|------|-------------|------|
| D1 | Anim Blueprint | `Content/Characters/ABP_Manny` | 基于 SKM_Manny 新建，后续 Step 逐步完善 |

创建方法：
1. Content Browser → 右键 → `Animation` → `Animation Blueprint`
2. 目标骨骼 → `SKM_Manny`
3. Anim Instance 类 → 默认 `AnimInstance`
4. 命名为 `ABP_Manny`

## 三、下载顺序建议

1. **先下载 B1~B3**（Idle/Walk/Jog）→ 搭配 D1 ABP_Manny + C1 BP_GASCharacter → 能移动
2. **再下载 B9**（Cast）→ 手搓 C2 火球蓝图 → 做 Step 1.2 弹道技能
3. **逐步补齐** B4~B12，跟着 Step 推进

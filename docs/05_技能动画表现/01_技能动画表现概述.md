# 05 - 技能动画表现

> 参照对象：漫威争锋 (Marvel Rivals)
> UE5版本：5.3+

---

## 一、技能动画表现概述

技能动画表现是连接 GameplayAbility 和 动画蓝图 的桥梁。主要涉及 Montage 播放、AnimNotify 事件、GameplayTag 驱动动画状态切换等。

### 核心组件

| 组件 | 作用 | 漫威争锋对应 |
|------|------|-------------|
| `AnimMontage` | 技能动画的播放容器 | 大招动画、近战连招 |
| `AnimNotify / AnimNotifyState` | 动画中的事件触发点 | 伤害判定窗口、特效生成时机 |
| `AbilityTask_PlayMontageAndWait` | GA中异步播放Montage | 技能动画播放与等待 |
| `GameplayTag` 驱动状态机 | 通过Tag切换AnimBP状态 | 受击/死亡/眩晕状态切换 |
| `Slot` (动画槽) | 不同优先级动画的混合 | 上半身射击槽、下半身移动槽 |

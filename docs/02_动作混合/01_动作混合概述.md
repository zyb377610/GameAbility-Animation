# 02 - 动作混合概述

> 参照对象：漫威争锋 (Marvel Rivals)
> UE5版本：5.3+

---

## 一、动作混合核心概念

动作混合（Animation Blending）是指多个动画源按照一定规则融合输出最终Pose的技术。漫威争锋中大量使用动作混合实现流畅的角色表现。

### 核心组件

| 组件 | 作用 | 漫威争锋对应 |
|------|------|-------------|
| `BlendSpace 1D/2D` | 根据参数在多个动画间平滑过渡 | Idle→Walk→Run速度过渡 |
| `AimOffset` | 基于瞄准角度的叠加动画 | 角色转身时上半身微调 |
| `LayeredBlendPerBone` | 按骨骼分层混合不同动画 | 移动+射击分离 |
| `Animation Layering` | 通过AnimLayer接口组合动画 | 武器动画层/移动动画层 |
| `Inertialization` | 动画切换时的惯性混合 | 动作突然中断时的平滑过渡 |

5. [ ] Inertialization在技能打断时的应用

## 三、漫威争锋观察要点

- 观察不同英雄移动时上半身的独立表现（尤其射击英雄）
- 注意转向动画的平滑程度（BlendSpace 2D的方向过渡）
- 飞行英雄的动作混合与地面英雄的差异
- 观察快速连续操作时的动画响应（Inertialization是否起效）

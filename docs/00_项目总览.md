## 二、技术栈

```
Python (Nepy)
├── 调用 UE5 C++ API（通过 Nepy 自动绑定）
├── 编写 GameplayAbility / GameplayEffect（纯 Python 类继承）
├── 控制动画蓝图参数、Montage 播放
├── 热重载：修改 .py 即刻生效，无需重启编辑器
└── UE-MCP：外部 AI 助手通过 WebSocket 操控编辑器
```

## 五、通用 AI 规则（每个新聊天必读）

1. **只用 Python + Nepy**：不写 C++，不创建 `.h/.cpp` 文件
2. **API 优先验证**：写代码前先从 `Plugins/NePythonBinding/Tools/pystubs/ue/__init__.pyi` grep 验证 API 存在性和签名。不要假设 API 存在。
3. **API 用 PascalCase**：`InitStats`, `GetAttributeSet`, `FindClass` 等 API 用大驼峰，不是 snake_case。方法签名以 pystubs 为准。
4. **降级方案**：如果 Python API 不支持某个操作，改用蓝图手动配置，Python 注意做运行时动态控制
5. **所有脚本放 `Content/Scripts/` 下**：按模块分子目录（`gas/`、`animation/` 等）
6. **新模块记得 import**：所有 Python 模块（尤其是含 `@ue.uclass()` 的），必须在 `Content/Scripts/nepyinit.py` 的 `on_init()` 中 import，否则 UE 反射系统不注册
7. **完成一步更新总览**：做完后把本文档状态表对应 Step 改为 ✅

## ⚠️ NePy 关键避坑清单（每次写 `import ue` 代码前过一遍）

> 以下来自实测血泪教训，下列写法均会导致报错或静默失败。

| 坑 | 错误写法 | 正确写法 |
|----|---------|---------|
| **日志** | `ue.log_error(...)` | `ue.log_warning(...)` 或 `print(...)` |
| **CDO 加组件** | `cdo.AddComponentByClass(...)` | CDO 无 World，不可用。在蓝图编辑器手动加，或运行时给 Actor 实例调用 |
| **@ue.uclass 属性** | `health: float = 100.0` | `Health = ue.uproperty(100.0)` — 必须用 `ue.uproperty()` |
| **AttributeSet 类引用** | `GetAttributeSet(AttrSet_Base)` | `GetAttributeSet(AttrSet_Base.Class())` — 必须 `.Class()` |
| **__init_default__** | `def __init_default__(self): ...` | `def __init_default__(self): ...` — Nepy 不支持 Python __init__ |
| **__init_default__ 中初始化 Python 变量** | `self._cache = {}` / `self._handle = None` | **禁止。** 仅能配置 ue.ucomponent 默认值。Python 状态用懒初始化或模块级闭包 |
| **热重载后类型判断** | `isinstance(x, MyClass)` | `hasattr(x, 'some_attr')` — 重载后 isinstance 可能失效 |

完整 NePy 编写规范位于 `.codemaker/codewiki/nepy/class-authoring.md` 和 `project-setup.md`。
如需对外部 AI 工具使用这些知识，仓库地址：https://github.com/zyb377610/CodeWikiForNepy
